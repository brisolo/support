# Brisolo — suporte / support

**Português.** Este é o canal de suporte dos plugins da Brisolo. Para relatar um
problema ou pedir ajuda, abra uma *issue* em
[github.com/brisolo/support/issues](https://github.com/brisolo/support/issues)
(não inclua senhas, chaves de API nem dados de clientes) ou escreva para
**brisolo.support@gmail.com**.

**English.** This is the support channel for Brisolo plugins. To report a problem or ask
for help, open an issue at
[github.com/brisolo/support/issues](https://github.com/brisolo/support/issues)
(never include passwords, API keys or customer data) or write to
**brisolo.support@gmail.com**.

## EntregaFlow

- **Artigos de ajuda (pt-BR):** [docs/entregaflow](docs/entregaflow/)
- **Procuramos testadores.** O EntregaFlow 0.1.0 é uma versão inicial: segue a documentação da API dos Correios, mas ainda não foi confirmado por lojas com contrato em produção. Se você tem contrato com os Correios, instale em uma loja de teste, use "Conferir com os Correios" (Configurações > EntregaFlow) com um pacote e compare com o simulador do seu contrato (SEDEX e PAC, com e sem valor declarado). Abra uma issue com a tabela e o resultado do simulador — sem o código de acesso.
- **Testers wanted.** EntregaFlow 0.1.0 is an early version: it follows the Correios API documentation but has not yet been confirmed by shops with a live contract. If you have a Correios contract, please try it on a test shop, run "Check with Correios" for one parcel and compare with your contract's simulator; open an issue with the table (never your access code).
